# PP Manufacturing Dashboard – System Architecture 
 
--- 
 
## 易 SYSTEM OVERVIEW  
 
This system is a multi-tenant SaaS dashboard for a Polypropylene (PP) Manufacturing plant. 
 
It digitizes the existing Excel-based workflow **without altering business logic**. 
 
### Core Modules: 
1. Dispatch Management   
2. Receivables (Client Invoices & Recovery)   
3. Client Summary Dashboard   
4. Payables (Vendor Liabilities)   
5. Cash Flow (Bank Transactions)   
 
### Linking Logic: 
Modules are loosely connected using: 
- invoice_no   
- client_name   
- vendor_name   
 
No strict relational enforcement.

- Transactions → transaction_id

- If match → update
